# 功能清单（Roadmap / 验收口径）

> 本文件是**唯一的需求台账**：所有需求先在这里登记（分配 ID），实现后把状态改成「已完成 + 版本号」。
> 优先级：**P0 = 没有它不能发版**；P1 = 首个正式版之前要有；P2 = 有则更好，可延后。
> 与 [RULES.md](../RULES.md) 冲突时以 RULES.md 为准。

图例：`⬜ 未开始` / `🟨 进行中` / `✅ 已完成` / `⏸ 暂缓`

## H. 明确不在本期范围

| 项 | 原因 |
|---|---|
| 手机 / 平板适配 | 目标设备是电视；手机端已有独立项目 |
| 云端账号、跨设备同步 | 违背「不联网也能用」的定位 |
| 内置源 / 一键导入热门源 | 见 RULES §2 |
| 录制、时移落盘 | 依赖源能力与存储，放 M4 之后单独评估 |
| 投屏 / DLNA | 与核心体验无关，长期候选 |
