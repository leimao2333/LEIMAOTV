**这一版加了「回看」**：源支持回看的台，按 OK 打开控制条会多一个「回看」按钮，可以选一档已经播完的节目从头看。没声明回看能力的台不会出现这个按钮 —— 不是点进去才告诉你「不支持」。

- 有节目单的台按节目名选；没有节目单的台按时间段选（整点一档）
- 回看时画面顶部会写明「回看 20:00–21:30」，控制条里有「回直播」，随时回到当前节目
- 回看播不了时只提示这一档坏了，不会把你自动切到别的台
- 修：播放失败的面板上，方向键推不动焦点（重试 / 换线路 / 下一个台 按不到）
