## 3. §9.2 手工验收 —— 逐条结果

### 3.1 启动路径四条（§6.6）—— ✅ 全通过

| # | 场景 | 构造方式 | 结果 |
|---|---|---|---|
| 1 | 有上次频道 → 冷启动直达播放并出画 | 正常重启 | ✅ 直达播放页，CCTV5+ CBA 直播真实出帧 |
| 2 | 上次频道被删 → 降级收藏第一个 | 删掉 history 指向的频道 + 只收藏 CCTV8 | ✅ 落在 CCTV8，控制条显示「★ 已收藏」 |
| 3 | 收藏为空 → 降级列表第一个 | 清空 favorite / history | ✅ 落在 `ORDER BY number, id` 的首个频道（CCTV3）并出画 |
| 4 | 删掉全部源 → 添加源引导页 | 全新安装 **release** 包（零内置源） | ✅ 同意合规后落「源管理 / 还没有订阅源」 |

### 3.2 主流程串联 —— ✅ 通过

冷启动 → 播放页 → 返回主页 → 切模式（直播↔影视）→ 进直播 → 换台 20 次 →
进影视 → 搜索 → 详情 → 播放 → 逐级返回，全程无崩溃、无卡死。

- 换台 20 次：每次切换都有 HUD 反馈，最终停在目标频道；遇到死流时降级链自动试完全部线路。
- 搜索：关键词提交 → 结果列表带真实海报（`搜索结果 7 条`），底部提示「某源没查完，结果可能不全」（聚合源部分站点超时）。
- 影视播放：大理寺日志3 第 01 集真实出画，进度条 / 选集 / 倍速面板均可用。

### 3.3 换模式不中断播放（HOME-02）—— ✅ 通过

直播播放中返回主页 → 切到影视 → 切回直播 → 点 Hero 回直播：

- 切换全过程 `logcat` **无任何** `ExoPlayerImpl` / `VLC-std` / `MediaCodec` 重建记录；
- 首页 Hero 始终显示「正在直播 CCTV5+」；
- 回直播页即刻出画，不需要重新缓冲。

### 3.4 弱网 + 断网 —— ✅ 通过（有改进项）

| 场景 | 表现 |
|---|---|
| 断网（`svc data disable`，Active default network: none） | 逐条试完 5 条线路后给失败面板：「这个台暂时播不了 / 软解也解不了这个源 · 已尝试 5 条线路」，附重试 / 换线路 / 下一个台 / 去源管理 |
| 恢复网络 | 点「下一个台」立刻恢复播放（CGTN 出画） |
| 弱网（`emu network speed umts`） | 画面卡住但界面不卡死，控制条可操作；自动换到线路 2，带宽恢复后继续播 |

改进项（未做）：弱网缓冲期目前是黑屏 + 控制条，没有「正在缓冲」的显式提示。

### 3.5 直播源失效（404 / 超时）—— ✅ 通过

- 失效频道（线路全死）→ 失败面板写明「已尝试 N 条线路」，四个出口齐全；
- 单个频道只有部分线路失效时，内核降级链自动跳到可用线路，用户无感。

### 3.6 遥控器全流程 —— ✅ 通过

本轮所有操作均使用 `adb shell input keyevent`（方向键 / OK / BACK / 数字键），未使用触摸：

- 导航栏：选中栏目自动收起；到最左按 ← 拉出并落回导航项；
- 播放页：↑↓ 换台、←→ 换线、OK 唤控制条、BACK 收起控制条 / 退出；
- 搜索页依赖系统输入法（SEARCH-06 九宫格键盘仍未做，属 M3 阻塞项），
  方向键可在结果间移动、OK 进详情。

### 3.7 真机 + 模拟器双通过 —— ⏳ 未完成

当前没有真机盒子可用，仅完成模拟器（1080p）。**发正式版前仍需一台真机补测**，
重点：冷启动到首帧 ≤ 2s（PLAY-09）、遥控器实际手感、libVLC 在各家盒子固件上的解码兼容性。

## 4. 本轮发现并修复的缺陷

| # | 缺陷 | 影响面 | 修复 |
|---|---|---|---|
| 1 | **release 包启动即闪退**：R8 未 keep `org.videolan.libvlc.**`，`libvlcjni.so` 的 JNI_OnLoad 返回 JNI_ERR，库自身 `System.exit(1)` | 所有正式包（v0.2.9.10 / v0.3.0.0 均受影响） | `app/proguard-rules.pro` 补 keep 规则并注明原因 |
| 2 | **影视播放页按 BACK 退不出去**：控制条收起时预览键把 BACK 也吞掉，形成「亮控制条 → 收起控制条」死循环 | 影视播放页遥控器操作 | 收起态放行 `Key.Back` |
| 3 | 源管理列表整块不显示：按钮行第 6 张卡片被挤压换行、撑高整行把列表顶出屏幕 | 所有尺寸下的源管理页 | 按钮行改横向滚动 |
| 4 | 影视页筛选区（年份/地区/标签）在聚合源下撑满整屏 | 聚合源用户的影视首页 | 改为「筛选」折叠开关，默认收起 |
| 5 | 海报全部不加载：Coil 用自带 OkHttp，不走应用代理设置 | 隔离网络 / 代理环境 | `ImageLoader` 复用 `AppContainer.okHttpClient` |
| 6 | 影片行尾露半张卡 | 影视首页各海报行 | `BoxWithConstraints` 按可用宽度整除均摊 |

## 6. 结论

M2 的**功能目标已达成**：影视源能出内容（含几十个站点聚合）、详情能选集、能播、记得住进度，
并且在自己的聚合影视源上跑通了真实链路。

§9.2 的前五项在模拟器上逐条通过；第 6 项（真机）待补。发 M2 正式版前，建议只用
`v0.3.0.1` 及以上版本 —— `v0.3.0.0` 及更早的 release 包存在启动闪退问题。
